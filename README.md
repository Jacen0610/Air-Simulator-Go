# Air-Simulator-Go

这是一个基于Go语言的航空模拟器项目。

---

## 分支

- **main**：这是主分支，模拟传统ACARS报文的发送，支持单信道模式和双信道模式，通信方式为经典p-坚持的CSMA/CA协议。独立运行，无需配合Python的RL框架。
- **Multi-Agent**：这是一个多智能体分支，设想在每架飞机上使用RL-Agent来自主决定是否在当前时隙内发送消息，支持单信道模式和双信道模式，需配合Python的RL框架使用。

---

本项目的设计思路如下：
1. 模拟所用到的相关类以及实例都在simulator包中；collector包负责在模拟结束时统计数据将模拟结果存入report文件夹下。
2. 这是一个以地面站为中心，30分钟航程为半径的模拟环境。simulator包中的simulation_plan.go负责控制生成多少架飞机以及飞机何时开始进入模拟环境。
3. 地面控制站负责接收报文消息并发送ack确认报文。
4. 参数设置都在config包中的config.go文件中，用户可以根据需要修改参数。
5. *Multi-Agent分支在main分支的基础上增加grpc功能(内容在proto包中)，用于与Python的RL框架通信。并能够循环模拟，结束模拟请使用crtl+c。
6. *RL的奖励(Reward)函数在api包中的server.go中，后续可以对奖励函数进行调参优化。RL框架设计在Ptython端，可以使用不同的RL框架，如PPO、A2C和DQN等自定义框架。
7. *这是多智能体共享同一个通信环境的模拟，智能体根据proto文件定义的感知状态(Observation)进行动作(Action)，有三种动作：无所作为、在主信道发送信息、在备用信道发送信息。针对不同观测状态下的不同动作奖励函数给出不同奖励或者惩罚。更新神经网络(即将学习经验进行总结)的频率可以在python端设置，目前是2000步(Step)更新一次网络。

## 使用
请先安装golang1.24版本或是之后版本（在中国大陆地区安装完成之后需要更改goproxy以免安装依赖失败）
```bash
# 在项目根目录下运行
go run main.go
```
