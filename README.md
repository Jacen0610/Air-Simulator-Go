# Air-Simulator-Go

## 1. 项目简介

**Air-Simulator-Go** 是一个基于 Go 语言构建的航空通信网络模拟器。它专注于模拟一个简化的 ACARS (飞机通信寻址与报告系统) 网络，其中多架飞机 (`Aircraft`) 和地面控制中心 (`GroundControlCenter`) 通过有限的、可能发生拥塞的数据链信道进行通信。

本项目的核心目标是利用**多智能体强化学习 (MARL)** 的思想，让每个通信实体（飞机和地面站）作为独立的智能体 (Agent)，学习在复杂的网络环境中优化其消息发送策略，以最大化通信效率和成功率，同时最小化延迟和冲突。

## 2. 核心概念

### 2.1. 模拟实体

-   **Aircraft (飞机)**: 模拟中的主要通信单元。根据预设的飞行计划 (`simulation_plan.go`)，飞机会产生不同类型的 ACARS 报文（如位置报告、燃油报告、引擎状态等），并尝试将它们发送到地面。
-   **GroundControlCenter (地面控制中心)**: 接收来自飞机的报文，并为每条成功接收的报文回复一个确认 (ACK) 消息。
-   **CommunicationSystem (通信系统)**: 包含一个或多个 `Channel` (信道)，是所有实体共享的通信媒介。

### 2.2. 通信协议

模拟器实现了一个类似于 **p-坚持 CSMA (载波侦听多路访问)** 的简化信道接入协议：
1.  **侦听 (Listen)**: 发送前，智能体检查信道是否繁忙。
2.  **坚持 (Persist)**: 如果信道空闲，智能体以概率 `p` 发送消息。如果未发送，则等待一个时隙后继续侦听。
3.  **碰撞 (Collision)**: 如果两个或更多实体在同一时刻发送消息，就会发生碰撞，导致消息传输失败。

### 2.3. 强化学习 (RL) 框架

-   **智能体 (Agent)**: 每个 `Aircraft` 和 `GroundControlCenter` 都是一个独立的智能体。
-   **观测 (Observation)**: 在每个决策点，智能体观察当前环境状态，包括：
    -   信道是否繁忙 (`PrimaryChannelBusy`, `BackupChannelBusy`)
    -   自身待发消息队列的长度 (`OutboundQueueLength`)
    -   队列中第一条消息的等待时间 (`TopMessageWaitTimeSeconds`)
-   **动作 (Action)**: 基于观测，智能体可以做出以下决策之一：
    -   `ActionWait`: 等待下一个决策时机。
    -   `ActionSendPrimary`: 尝试在主信道发送。
    -   `ActionSendBackup`: 尝试在备用信道发送。
-   **奖励与惩罚 (Reward/Penalty)**:
    -   **正奖励**: 成功发送消息会获得奖励。奖励的多少与消息的等待时间挂钩，等待时间越短，奖励越高（采用线性衰减函数）。
    -   **负奖励 (惩罚)**:
        -   发生**碰撞**会受到重罚。
        -   在信道空闲时选择**等待**会受到惩罚，且惩罚力度随队列长度和等待时间的增加而加大。
        -   消息因超出最大重传次数或等待过久而被**丢弃**会受到重罚。

## 3. 项目结构

```
/
├── api/                  # (可选) API服务器，用于外部交互
├── collector/            # 数据收集与报告生成
│   └── collector.go
├── config/               # 模拟器的核心配置文件
│   └── config.go
├── report/               # 生成的Excel报告的输出目录
├── simulation/           # 核心模拟逻辑
│   ├── aircraft.go       # 飞机实体的定义与行为
│   ├── center.go         # 地面站实体的定义与行为
│   ├── channel.go        # 通信信道的定义
│   ├── messages.go       # ACARS消息类型的定义
│   └── simulation_plan.go # 预设的飞行计划
├── main.go               # 程序主入口
└── README.md             # 本文件
```

## 4. 如何运行

### 4.1. 前提条件

-   已安装 Go 语言环境 (版本 1.18 或更高)。

### 4.2. 运行模拟

在项目根目录下，执行以下命令：

```bash
go run main.go
```

模拟将开始运行，并在控制台输出详细的日志信息，包括飞行计划的启动、消息的生成与发送、碰撞、ACK确认、超时重传等事件。

## 5. 输出结果

模拟结束后，会在 `/report` 目录下生成一个带有时间戳的 Excel 文件，例如 `simulation_report_episode_0.xlsx`。该报告包含以下工作表：

-   **Aircraft_Stats**: 记录了每架飞机在模拟过程中的详细统计数据，包括：
    -   成功传输数、重传数、**丢弃消息数**
    -   总尝试传输数、碰撞次数、碰撞率
    -   平均等待时间 (ms)
-   **GroundControl_Stats**: 记录了每个地面站的类似统计数据。
-   **Channel_Stats**: 记录了每个信道的使用情况，包括：
    -   总传输消息数
    -   总繁忙时间、信道使用率
-   **Wait_Time_Distribution**: 记录了**所有**成功发送的消息（无论来自飞机还是地面站）在队列中的原始等待时间（单位：ms）。此数据可用于分析消息延迟的分布情况。
